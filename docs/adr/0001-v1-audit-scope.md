# v1 audit scope is max supply + circulating only

Original spec mixed governance, team allocation, narrative summary, and a 20% “healthy” dilution label. We locked v1 to a single Document Claim (`maxSupplyAmount` in human units), a Market Snapshot (`circulating`), and Findings: Pending Dilution (percent only), Missing Max Supply, and Source Conflict. Everything else (textual governance, scores, narrative) waits for a stronger source or a later ADR — otherwise Proof of Work and the Deterministic Engine drown in unverifiable claims.
